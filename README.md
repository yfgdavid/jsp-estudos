# Crud_JSP

> Aplicação web desenvolvida em Java com JSP e Servlets, implementando um CRUD completo para praticar a lógica MVC e aplicar em projetos reais.

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de entender na prática o padrão **MVC** utilizando tecnologias Java para web, realizando operações de **Create, Read, Update e Delete** com persistência em banco de dados.
